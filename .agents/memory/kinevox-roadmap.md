name: KinevoX roadmap
description: The user-defined product sequence for KinevoX.
---

The user’s roadmap is staged:

1. Foundations: inspect all MVP pages, support phone and desktop, complete and validate onboarding, and save plans and progress reliably.
2. Core product: complete the reviewed exercise and program library, use clear recommendation rules, provide workout history and progress, and finish Arabic and English support.
3. Trust and quality: test accounts, permissions, and security; provide privacy and account deletion; test with 5–10 beginners; collect feedback and fix issues.
4. Expansion: add an AI assistant only after trustworthy content is ready, improve analytics, test a suitable revenue model, and add features based on user requests.

**Why:** the user explicitly supplied this order as the product roadmap.

**How to apply:** prioritize local MVP reliability before expansion; do not present content as reviewed without a real qualified review; defer AI until then; use beginner feedback to choose later features. Account-specific security and deletion apply only if KinevoX introduces accounts.
